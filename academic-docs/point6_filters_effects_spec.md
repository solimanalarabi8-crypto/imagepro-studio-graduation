# مواصفات النقطة السادسة: الفلاتر والمؤثرات
## ImagePro Studio — Functional Point 6: Filters & Effects Specification

استناداً إلى وثيقة مشروع التخرج `academic-docs/imagepro_graduation_plan.md` (السطور 160-186):

### 1. الهدف
إضافة مجموعة فلاتر متكاملة (22 مرشحاً عملياً وفنياً) مقسمة عبر 7 فئات رئيسية، تعمل مباشرة عبر المعالجة النقطية لمصفوفة البكسلات `ImageData` والالتفاف الرياضي، مع شريط تحكم ديناميكي في الشدة وإمكانية الاعتماد النهائي (Bake).

### 3. تجربة المستخدم ولوحة التحكم
1. **أزرار تصنيف الفلاتر (Category Filter Tabs):** تتيح تصفية المعرض بين (الكل، تمويه، حدة، حواف، ضوضاء، هندسية، لونية، فنية).
2. **بطاقة التحكم التفاعلية (Active Filter Tuning Card):** تظهر فور اختيار أي مرشح وتتيح:
   - اسم المرشح ووصفه وتصنيفه.
   - شريط تمرير حي (Slider) لضبط شدة الفلتر مع معاينة فورية بدون تأخير.
   - زر **اعتماد التأثير (Bake)** لحفظ النتيجة في طبقة الصورة الأساسية وتفريغ المعالج لعمليات جديدة.
   - زر **إلغاء** للرجوع للصورة الطبيعية بنقرة واحدة.
3. **قائمة الشريط العلوي (مرشح):** تشمل الفلاتر الـ 22 مع شارات التصنيف والعتبة الثنائية.
4. **التكامل مع السجل والتراجع:** تدعم التراجع (Undo) والتقدم (Redo) لكافة الفلاتر وحفظ الحالة.

### 4. نتائج التحقق والاختبار
- 6 ملفات اختبارات و 27 فحص وحدة ناجحة بنسبة 100% عبر Vitest.
- فحص TypeScript نظيف تماماً (`tsc --noEmit` خالي من الأخطاء).
- بناء الإنتاج Vite Bundle جاهز وخالٍ من أي تعارضات.
