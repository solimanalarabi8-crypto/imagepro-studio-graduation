# المرحلة الرابعة: الوظائف المتقدمة
## ImagePro Studio — Advanced Editing Features Specification

**الحالة:** مواصفة تنفيذية معتمدة قبل البرمجة  
**الهدف:** رفع المحرر من مستوى المعالجة الأساسية إلى تحرير متعدد الطبقات قابل للتحكم وغير تدميري.

## 1. نطاق المرحلة

تركز المرحلة الرابعة على خمس وحدات مترابطة: التحديد المتقدم، أقنعة الطبقات، النص القابل للتحرير، القطّارة، وإدارة الطبقات المتقدمة. لا تعني هذه المرحلة إضافة خوارزميات ذكاء اصطناعي؛ بل تعني بناء أساس هندسي مضبوط يمكن توسيعه لاحقاً.

## 2. المتطلبات الوظيفية

| الرمز | المتطلب | معيار القبول |
|---|---|---|
| AF-01 | إنشاء تحديد مستطيل وبيضاوي وحر | تظهر حدود التحديد في الموضع الصحيح ويمكن تعديلها أو إلغاؤها |
| AF-02 | إضافة وطرح مناطق التحديد | ينتج نطاق مركب مطابق للعملية المطلوبة |
| AF-03 | عكس وتنعيم التحديد | تتغير الحدود دون تعديل الصورة الأصلية |
| AF-04 | تحويل التحديد إلى قناع | تخفي المنطقة المحددة أو تظهرها دون حذف البيانات الأصلية |
| AF-05 | إنشاء نص قابل للتحرير | يمكن تغيير النص والحجم واللون والموقع دون إعادة رسم الصورة الأصلية |
| AF-06 | التقاط لون من Canvas | تعرض الأداة قيمة RGB وHEX للنقطة المحددة |
| AF-07 | إدارة الطبقات المتقدمة | يمكن تحديد طبقات النص والرسم والقناع وإظهارها أو إخفاؤها باستقلالية |
| AF-08 | حماية الطبقات غير المستهدفة | لا تؤثر الممحاة أو أي عملية على طبقة غير محددة |

## 3. نموذج الحالة

يمثل التحديد بيانات مستقلة عن Canvas، وتمثل الأقنعة والنصوص كعناصر طبقات. لا يسمح التصميم بتحويل جميع العناصر إلى بكسلات نهائية قبل التصدير، حفاظاً على قابلية التعديل.

```text
EditorState
├── project
│   ├── layers[]
│   ├── selections[]
│   ├── activeLayerId
│   └── activeTool
├── renderState
│   └── preview / export
└── history
    ├── undo[]
    └── redo[]
```

## 4. ترتيب التنفيذ

يبدأ التنفيذ بنموذج Selection وعرض حدوده، ثم تضاف عمليات الجمع والطرح والعكس. بعد ثبات التحديد، يربط بقناع Layer Mask. بعدها تضاف طبقات النص والتحرير، ثم القطّارة، وأخيراً يعاد تنظيم لوحة الطبقات لتعرض نوع كل طبقة وحالتها.

## 5. خطة الاختبار

تختبر كل وحدة على صورة ملونة وصورة شفافة وصورة ذات أبعاد مختلفة. تشمل الاختبارات الحدودية تحديد مساحة صفرية، تحديداً خارج Canvas، طبقات مخفية، طبقة مقفلة، نصاً فوق الصورة، استخدام الممحاة فوق النص، والتراجع بعد كل عملية.

## 6. القيود المعروفة

في هذه المرحلة يكون التحديد الحر مبنياً على نقاط مسار، وقد يحتاج لاحقاً إلى خوارزمية raster mask أدق. كما أن القطّارة تقرأ اللون من المعاينة الحالية، بينما يمكن إضافة قراءة اللون من الطبقة الأصلية كخيار متقدم.

## 7. مخرجات المرحلة

المخرج المتوقع هو محرر يحتوي على تحديد واضح، أقنعة غير تدميرية، نص قابل للتحرير، قطّارة، ولوحة طبقات أكثر دقة، إضافة إلى سجل اختبارات يبين نتيجة كل معيار قبول.
