# مواصفات النقطة الخامسة: تحسين الإضاءة والألوان
## ImagePro Studio — Functional Point 5: Lighting & Color Adjustments

استناداً إلى وثيقة مشروع التخرج `academic-docs/imagepro_graduation_plan.md` (السطور 140-158):

### 1. الهدف
تقديم لوحة تعديلات احترافية تسمح بضبط مظهر الصورة مع معاينة مباشرة وسريعة على Canvas، وإمكانية إعادة ضبط كل قيمة منفردة أو تطبيق التعديلات نهائياً.

### 2. بنود التنفيذ
| الميزة | النوع | النطاق والقيمة الافتراضية | الوصف |
|---|---|---|---|
| السطوع (Brightness) | أساسي | -100 إلى +100 (افتراضي 0) | رفع أو خفض إضاءة الصورة العامة |
| التباين (Contrast) | أساسي | -100 إلى +100 (افتراضي 0) | توسيع أو تضييق الفارق بين الفاتح والداكن |
| التشبع (Saturation) | أساسي | 0 إلى 200% (افتراضي 100) | شدة تشبع الألوان أو سحبها |
| تدرج اللون (Hue) | أساسي | -180° إلى +180° (افتراضي 0) | دوران زاوية الألوان على دائرة اللون |
| التعريض (Exposure) | أساسي | -100 إلى +100 (افتراضي 0) | محاكاة حساسية المستشعر وكمية الضوء |
| حرارة اللون (Temperature) | أساسي | -100 إلى +100 (افتراضي 0) | توازن دافئ (برتقالي) إلى بارد (أزرق) |
| جاما (Gamma) | أساسي | 0.2 إلى 2.5 (افتراضي 1.0) | ضبط انحناء المنحنى النغمي غير الخطي |
| تدرج رمادي / سيبيا / عكس | أساسي | 0 إلى 100% | مؤثرات نغمية أحادية |
| العتبة (Threshold) | أساسي | 0 إلى 255 (افتراضي 128) | تحويل الصورة إلى أسود وأبيض نقي ثنائي |
| توازن الألوان (Color Balance) | متقدم | R, G, B منفصلة (-100 إلى +100) | تصحيح قنوات الألوان الأساسية |
| الهيستوجرام الحي (Histogram) | متقدم | 256 مستوى لقنوات R, G, B والإضاءة | رسم بياني يعكس توزيع البكسلات فورياً |
| زر تصفير فردي لكل خاصية | متطلب قبول | نقرة واحدة على زر ⟲ بجانب السلايدر | إعادة القيمة الافتراضية الخاصة بهذا السلايدر فقط |
| زر اعتماد وتطبيق (Apply) | متطلب قبول | زر تثبيت التعديلات | حفظ التعديلات في سجل التاريخ وتمكين التراجع |

### 3. معايير القبول والاختبار
1. استجابة المعاينة فورية على Canvas (120 FPS).
2. دقة حساب الهيستوجرام عبر اختبارات آلية بنسبة 100%.
3. كل زر تصفير فردي يعيد قيمته الافتراضية بدقة دون التأثير على بقية السلايدرات.
