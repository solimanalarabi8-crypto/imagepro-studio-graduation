# مواصفات النقطة السابعة: الرسم والتلوين والأشكال
## ImagePro Studio — Functional Point 7: Digital Art, Drawing & Shapes Engine

استناداً إلى وثيقة مشروع التخرج `academic-docs/imagepro_graduation_plan.md` (السطور 187-202):

---

### 1. الهدف
تحويل المحرر من مجرد أداة لتعديل الصور إلى مساحة تصميم ورسم رقمي متكاملة (Digital Art Studio) تتيح الرسم الحر المتقدم، الأشكال الهندسية المتنوعة، التلوين الفيضاني، والتحكم التام بالألوان والفرش والطبقات مع دعم كامل للتراجع.

---

### 2. الأدوات المنفذة ومواصفاتها الهندسية

| الأداة | الاختصار | المواصفات الهندسية والخوارزمية |
|---|---|---|
| **الفرشاة (Brush)** | `B` | خوارزمية تنعيم المسارات بالمنحنيات التربيعية (Quadratic Bezier Midpoint Spline Smoothing) لإلغاء أي تسنن أو اهتزاز يدوي. تحكم كامل بالحجم (1-120px)، العتامة (10-100%)، والصلابة/الترييش (0-100%). |
| **القلم الدقيق (Pencil)** | `N` | ضربات دقيقة صلبة بحواف حادة (100% Hardness) وحجم ناعم (1-4px) مخصصة للرسم التخطيطي وتحديد التفاصيل. |
| **الممحاة الذكية (Eraser)** | `E` | مسح موضعي انتقائي يستهدف ضربات طبقة الرسم المحددة فقط دون إتلاف الصورة الأصلية أو الخلفية أو النصوص، مع مؤشر دائري حي. |
| **دلو التلوين (Paint Bucket)** | `G` | خوارزمية الملء الفيضاني الموضعي (4-way Breadth-First Search Flood Fill) مع فحص تسامح وتفاوت لوني (Tolerance) لتلوين المساحات المتصلة فورياً. |
| **القطّارة (Eyedropper)** | `I` | التقاط دقيق للبكسل من الـ Canvas وقراءة كود HEX وقيم RGB وتحديث اللون الأمامي تلقائياً. |
| **الأشكال الهندسية (Shapes)** | `U` | دعم 5 أشكال رئيسية: مستطيل (Rectangle)، بيضاوي (Ellipse)، خط مستقيم (Line)، مثلث (Triangle)، ونجمة خماسية / مضلع (5-Point Polygon/Star). |

### 3. إمكانيات التحكم في الفرشاة والألوان (Studio Controls)

1. **نظام الألوان المزدوج (Dual Color Swatches):**
   - حقل تفاعلي لاختيار اللون الأمامي (Foreground Color) واللون الخلفي (Background Color).
   - زر تبديل سريع بنقرة واحدة أو عبر اختصار لوحة المفاتيح `X`.
   - زر استعادة الألوان الافتراضية (أسود / أبيض) بنقرة واحدة أو عبر اختصار لوحة المفاتيح `D`.
   - لوحة ألوان سريعة (10 ألوان عصرية جاهزة تشمل Teal, Blue, Purple, Pink, Red, Orange, Yellow, Green, White, Black).

2. **خصائص ضربات الرسم:**
   - **الحجم (Brush Size):** من 1 إلى 120 بكسل مع إمكانية التصفير للوضع الافتراضي (16px).
   - **العتامة (Opacity):** تحكم دقيق بشفافية الرسم من 10% إلى 100%.
   - **الصلابة (Hardness / Feathering):** تحكم بترييش حواف الفرشاة من 0% (ناعم جداً) إلى 100% (حواف حادة مصمتة).

3. **أنماط رسم الأشكال الهندسية (Shape Modes):**
   - **إطار فقط (Stroke):** رسم محيط الشكل باللون الأمامي وبالسماكة المحددة.
   - **تعبئة فقط (Fill):** تعبئة مساحة الشكل باللون الخلفي أو الأمامي بدون إطار.
   - **إطار وتعبئة معاً (Both):** محيط بلون وتعبئة داخلية بلون مكمل.

4. **عزل الطبقات والتراجع:**
   - كافة الرسومات والأشكال تحفظ ككائنات مستقلة مرتبطة بطبقة رسم (`layerId`).
   - حماية كاملة لطبقة الصورة الأساسية من التعديل التدميري.
   - تكامل 100% مع نظام التراجع والتقدم (Undo / Redo) وسجل التاريخ (History Steps).
   - توافق وحفظ كامل مع صيغة المشروع المصدرة `.imagepro`.

---

### 4. نتائج التحقق والاختبارات الآلية
- **الاختبارات الآلية (Vitest):** اجتياز 7 ملفات اختبارات و 30 فحص وحدة بنجاح 100% في زمن قياسي قدره 3.5 ثوانٍ.
- **فحص الأنواع (TypeScript Check):** خلو تام من أي أخطاء برمجية (`tsc --noEmit` بنتيجة Clean Code 0).
- **التشغيل المباشر:** استمرار عمل خادم التطوير Vite واستجابة الواجهة بدون أي أخطاء.
