# مواصفات المرحلة السادسة: الحفظ والتصدير
## ImagePro Studio — Phase 6: Save & Export Specification

استناداً إلى وثيقة الخطة الزمنية لمشروع التخرج `academic-docs/imagepro_graduation_plan.md` (السطور 427-430):
> **المرحلة السادسة: الحفظ والتصدير**
> تنفيذ الحفظ المحلي، تصدير JPG/PNG/WebP، واستعادة المشروع.

---

### 1. الهدف
تمكين المستخدم من تصدير عمله الفني بدقة عالية ومقاييس متعددة مع حفظ كامل للمشروع بهيكلته الطبقية لاستئناف العمل لاحقاً على أي جهاز آخر دون فقدان أي بيانات.

### 2. الوظائف المنفذة
1. **التصدير المتقدم متعدد الصيغ (Multi-Format Export):**
   - **PNG:** حفظ بتنسيق نقطي بدون فقدان (Lossless) مع دعم كامل لشفافية الطبقات.
   - **JPG / JPEG:** ضغط عالي الكفاءة مع شريط تحكم دقيق في نسبة الجودة (10% - 100%) وملء الخلفية باللون الأبيض النقي.
   - **WebP:** دعم التنسيق الحديث الموصى به لمحركات البحث والويب بجودة وضغط استثنائيين.
2. **مضاعف دقة التصدير (Resolution Scaling):**
   - إمكانية تصدير الصورة بمقياس **0.5x** أو **1.0x** أو **2.0x** (دقة مضاعفة فائقة للشاشات عالية الكثافة).
3. **حساب الحجم التقديري التفاعلي (Estimated File Size):**
   - خوارزمية ذكية تحسب الحجم المتوقع للملف بالكيلوبايت أو الميجابايت فورياً بناءً على الأبعاد ونسبة الجودة والصيغة المختارة.
4. **حزمة ملف المشروع المستقلة (.imagepro Project Package):**
   - تصدير كامل لحالة المحرر في ملف JSON مستقل بصيغة `.imagepro`.
   - يتضمن: بيانات الصورة، جميع الطبقات (Image, Paint, Text, Mask, Adjustment) مع درجات الشفافية وأوضاع الدمج، التعديلات اللونية الكاملة، الفلاتر النشطة وشدتها، وخطوط الرسم والأشكال والنصوص.
5. **استعادة المشروع (Project Import & Restore):**
   - إمكانية فتح أي ملف `.imagepro` من الجهاز أو استيراده بنقرة واحدة، واستعادة كامل بيئة العمل وطبقاتها وخطواتها فورياً.
6. **الحفظ والاستعادة المحلية (Local Storage):**
   - حفظ تلقائي وسريع للمشروع في ذاكرة المتصفح المحلية واستعادته بضغطة زر.

### 3. الاختبار والتحقق
- بناء ملف فحص الوحدات الآلي `client/src/lib/project-persistence.test.ts`.
- التحقق من دقة التسلسل (Serialization) وفك التسلسل (Deserialization) وخوارزمية تقدير الحجم.
- اجتياز جميع الفحوصات بنسبة 100%.
